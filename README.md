# Corgi Chomp 🐶

A browser game: help Biscuit the Cardigan corgi eat snacks smaller than she is (butter, cake, bread, mice, fish, ribs, bananas, fries, waffles) while dodging the ones that are too big. Every snack she eats makes her bigger, so foods that were dangerous at the start become edible later.

## Play

Open `index.html` in any browser. It has no dependencies and no build step.

- **Move:** mouse, touch, or WASD / arrow keys
- 🟢 Green ring: small enough to eat
- 🔴 Red ring: too big, and touching it costs a heart
- **P / Esc:** pause · **M:** mute
